# ProfileAuditor

## Project Introduction

ProfileAuditor is a proposed software engineering project for reviewing technical resumes. The system is intended to extract important resume information, compare technical claims with available public GitHub and LeetCode evidence, and provide understandable feedback.

The project addresses the problem of slow and inconsistent manual resume review. It will help users identify verified, unverified, and unavailable information while keeping the final decision with a human reviewer.

## Project Objectives

- Reduce the time required to review technical resumes.
- Organize evidence related to skills and projects.
- Provide a simple and explainable Reality Score.
- Give ATS and resume improvement feedback.
- Support fair and human-assisted resume evaluation.

## Project Scope

The proposed system will include PDF and DOCX resume upload, information extraction, public-profile verification, score calculation, ATS feedback, resume editing, and DOCX export. Automatic hiring decisions and large-scale applicant tracking are outside the project scope.
